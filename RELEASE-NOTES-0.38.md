# AW1K Panel 0.38

- **SMS spam filtresi** (SMS → Spam filtresi): kelimeye uyan SMS'i modem siler (uygulama kapalıyken de), göndericiyi engeller. "Silinmeyecek göndericiler" listesi, "Deneme (silmez)" ve silinenlerin kaydı var. Mesaj başına "Engelle" düğmesi.
- **Yeni SMS bildirimi** (Ayarlar → Bildirim): SIM'e SMS gelince bildirim; filtreye uyanlar bildirilmez. Telefon modemin Wi-Fi ağındayken çalışır.
- Oturum geçersizse ("Access denied") uygulama kendiliğinden yeniden giriş yapar.
- Gerekli: modemde KediRay 1.19.94 ya da yenisi (filtre betiği orada).
