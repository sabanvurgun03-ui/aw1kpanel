## Bu sürümde yeni / What's new

- Tüm sayfalar KediRay'in mor temasıyla yenilendi; sayfa geçişleri ve menü animasyonlu, menüde modem/VPN durumu ve rozetler var.
- Cihazlar sayfasında her cihaz için anlık hız (kablolu dahil), Wi-Fi'da sinyal; VPN sekmesinde canlı hız grafiği.
- Uygulama içi güncelleme: yeni sürüm GitHub'dan bulunur, indirilir ve kurulur.
- Klavye açılınca giriş ekranındaki üst üste binen alanlar düzeltildi.

- All pages redesigned in the KediRay purple theme, with animated page transitions and a new menu showing modem/VPN status and badges.
- Live per-device speed on the Devices page (wired too) and signal for Wi-Fi; live speed graph on the VPN tab.
- In-app update: new versions are found on GitHub, downloaded and installed.
- Fixed overlapping fields on the login screen when the keyboard opens.

## Kurulum / Install

Bu ilk güncelleme sistemli sürümdür, elle kur: APK'yı indir, "bilinmeyen kaynaklardan kurulum" iznini ver ve aç. Sonraki sürümleri uygulama kendisi bulur (Güncelleme sayfası). Modemde KediRay 1.19.36 veya yenisi gerekir.

This is the first release with the update system, so install it manually: download the APK, allow "install from unknown sources" and open it. Later versions are found by the app itself (Update page). Requires KediRay 1.19.36+ on the modem.
